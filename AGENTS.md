# Espinage

Reusable agent skills live in `skills/`. Read the relevant `SKILL.md` before using its workflow.

For monthly Instagram work-delivery reports, use [instagram-delivery-report](skills/instagram-delivery-report/SKILL.md). The complete skill includes the data-driven PDF renderer, versioned theme, sample input and rendered design preview. Follow [the template instructions](skills/instagram-delivery-report/references/template.md) and reuse the renderer for consistent output across accounts and agents.

Keep shared examples fictional. Client reports, private account insights, credentials and session data belong in the task workspace, outside this public repository.
