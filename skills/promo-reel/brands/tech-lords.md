# Tech Lords (@techlordsbywlm)

WordLord Media's AI-engineering and tech-breakdown channel. Not real estate: reels are Hinglish explainers for Indian developers and founders, not ads for a property. The shared craft still applies; facts here are technical claims, so every one needs a source (a paper, a post, a registry check).

- **Project:** `/Volumes/disk 2/techlords-reels` (`node_modules` symlinked to the kit's, Remotion 4.0.536). Films in `src/films/`, index in `docs/FILMS.md`.
- **Logo:** `public/brand/techlords.png` (from `Desktop/wordlord-brand-vault/assets/techlords.png`): charcoal `#353535` square, white T built from a slanted bar + triangle, orange L, "TECH LORDS" in wide tracked caps. Traced polygons (1254 px space) live in `src/brand.ts` (`LOGO`), so the mark can assemble shard by shard.
- **Tokens:** ground charcoal `#161618` → lift `#2A2A2D`; ink `#F2F0EC`; dim `#9C9A95`; hairline ink at 10 %; accent orange `#F24D07` (the logo's own, chroma above the 0.13 cap on purpose: it is the brand colour); pass green `#7CC08A` only for passing tests.
- **Type:** captions centred (owner, 22 Oct 2026), Geist (520 words + 760 orange hero word, soft orange glow, size 86, auto-fit to the slot; the 300 light weight read too thin on a phone); code and file names JetBrains Mono; brand name "TECH LORDS" in Geist 700 tracked 0.3 em (Archivo extended was replaced on the owner's note about the outro font).
- **Signature move:** the logo shards. Slanted slabs count any list of three and shrink into the progress mark; the TL mark assembles along its own diagonal at the end with one light sweep (logo at 520 px).
- **Information as UI:** code, file trees, terminals and markdown files are the real things these reels talk about, so they appear as real artefacts on one card face (hairline, top highlight, mono file-name tab). No browser bars, phone frames or dashboards.
- **Language:** Hinglish for the Indian audience (owner, 22 Oct 2026). English drafts were rejected.
- **Format:** the one-take house format, `docs/HOUSE-FORMAT.md` in the project. Separate static card scenes were rejected as "too static… all I see is terminal screens".
- **Cast:** a recurring host, Tech Lord (Charon, locked), with foils Bunty (Puck, locked) and Priya (Aoede, proposed) for conversation reels: `docs/HOST.md`. One voice per character in every reel.
- **Mascots:** the cast are SVG characters drawn in code (`src/stage/Mascot.tsx`) that lip-sync and change mood; the owner chose code over illustrated mascots (22 Oct 2026).
- **Frame:** cross-platform safe frame (x 80–930, y 250–1480); captions at y 320, hero window y 520–1040 when the cast is on screen, cast y 1050–1480. Every-second audit before calling a film done.
- **Scripts:** playful, sarcastic, joke-led, one hook + one non-linear structure per reel (skill `HOOKS.md`; project `docs/HOOKS.md`). Freebies live in the public repo `Juvaid/techlords-resources`, one folder per comment word.
- **Names get pictures:** every person, company, product or source the voice names appears on screen on its word (photo card, brand mark), from licensed sources with credit (owner, 22 Oct 2026).
- **Music:** "Future Technology Background" by MiroMaxMusic (Pixabay, no Content ID), chosen by the owner 22 Oct 2026 over the corporate track ("too happy for a tech video"). `public/audio/music.wav` is its two full-energy sections joined on the beat (84 s, no breakdowns), so every reel starts at full energy. Level: the bed file is −13.7 LUFS (lowered 7 dB, 1–2.5 kHz dipped for the voice) and every film's music curve is multiplied by `MUSIC_GAIN` (0.6, `src/stage/house.tsx`), so the music sits 6–13 dB under the −24 LUFS voice (owner: "music too loud"). Source note: `public/audio/MUSIC-SOURCE.md`.
- **News carousels (owner, 23 Oct 2026):** Instagram video carousels at 1080×1350, one ~5 s silent clip per slide (`src/carousel/Slide2.tsx` kit, data in `src/carousel/news.ts`, comps `N-<id>-<n>`). No mascots, no SFX, no chat bubbles: the first version with them was rejected. The headline is readable on frame 0 (static, `*accent*` markup, auto-fit per line), and the motion goes into the data visual: counters, growth arcs, bars, timelines, org trees, approve lists, chips. Use real brand marks (Simple Icons CC0, Wikimedia public-domain marks) and Phosphor duotone icons, never emoji or generic glyphs. Each slide carries a source line. Cover all of AI, tech, tools and open source, not only ChatGPT and Claude. Check every fact and date against a primary source (company newsroom, GitHub or Hugging Face API, Reuters), and confirm the release date: something reported as "today" may be days older. Captions live in the project's `docs/INSTAGRAM-KIT.md` §3b.
