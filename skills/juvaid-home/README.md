# Juvaid Home

Skill group for the tools that live with Juvaid, separate from the promo-reel skill.

Install one skill:

```bash
ln -s "$(pwd)/skills/juvaid-home/reel-intelligence" ~/.claude/skills/reel-intelligence
ln -s "$(pwd)/skills/juvaid-home/search-presence" ~/.claude/skills/search-presence
```

## In this group

| Skill | Status |
| --- | --- |
| `reel-intelligence` | Recovered from `~/.hermes/skills/reel-intelligence` (15 Sep 2026). Local Instagram Saved control plane. |
| `search-presence` | Public SEO, on-site business profile, DuckDuckGo/Bing snippet, and AI-crawler check. First profile is WordLord Media. |
